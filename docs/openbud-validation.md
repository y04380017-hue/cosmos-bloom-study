# V8：微开苞起始

本轮仅更新线上83种花及黄花波斯菊根入口，不生成或更新离线下载包。

## 行为

- 页面初始进度为0%，阶段名称为“微开苞”；首次打开、重置、拖动滑块及播放结束后重播使用同一起点。
- 显示进度0%对应原模型25%的露瓣姿态，0–50%连续映射到原25–50%，后半程沿用原时间段。50%和100%的花瓣顶点保持发布版 `4ac992fa03eaaa098f0983346343b6d3ad165f80` 的结果。
- 每次形变后隐藏包覆网格 `bud-cover`、`cosmos-bract`，以及桔梗的封闭替代网格 `balloon-bud`。茎、叶、花托和花冠基部仍保留。
- 通用模型与黄花波斯菊独立运行时都调用同一播放策略。物种配置、原图、纹理、花瓣曲面及物理材质未修改。

## 验证

`tests/verify-collection-ui.cjs` 执行全部83个发布HTML中的实际内嵌脚本，仅替换DOM与WebGLRenderer。检查初始露瓣、包覆隐藏、三阶段、重置、重播、拖动、暂停、视角、链接及原图散列。

`tests/half-full83-fixtures.json` 在修改产品代码前从上述发布版采集，保存83种花的半开和盛开花瓣顶点散列。新播放路径逐项匹配这些散列。原有 `baseline12-files.json` 仅更新本轮有意修改的 `prototype.html` 散列，照片、纹理、历史离线包的基准未变。

运行 `node tests/verify-all.cjs` 检查12组回归验证。针对黄花波斯菊、金盏花、天蓝绣球、芍药、木香花、桔梗、栀子花、西番莲另检查三个阶段的真实网格软件投影。

预览页面已显示新起始阶段与目录文字。当前预览浏览器报告 `GL_VENDOR = Disabled, GL_RENDERER = Disabled`，因此软件投影与替代渲染器验证不包含最终WebGL光影和帧率验收。
